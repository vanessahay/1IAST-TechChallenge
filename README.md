# 1IAST-TechChallenge

## Objetivo do Projeto
O objetivo deste projeto é desenvolver um modelo preditivo capaz de analisar dados históricos e fornecer insights acionáveis para a tomada de decisão estratégica, focando em eficiência e precisão.

## Problema de Negócio
Hoje, o NPS é retrospectivo e dificulta a prevenção de problemas. Este projeto busca mudar essa lógica: mapeamos os fatores que mais impactam a experiência e criamos um modelo preditivo para antecipar a classificação de cada cliente.

## Descrição da Base de Dados
A base de dados utilizada contém registros detalhados sobre as operações, incluindo variáveis categóricas e numéricas que descrevem o comportamento do sistema ao longo do tempo.

## Metodologia Utilizada
1. **Entendimento do negócio:** Criação do Target
2. **Exploração de Dados (EDA):** Limpeza e análise estatística inicial.
3. **Resumo executivo:** Resumo executivo com Insigts para as áreas de negócio e como cada área pode se beneficiar



## Como Reproduzir os Resultados
